# App Remix Kit

*[English](README.md) / 日本語*

[yukmmz.github.io](https://yukmmz.github.io/) で公開している小さなアプリを、**AI に頼んで自分好みに作り変え、自分の URL で公開する**ためのキットです。
プログラミング・GitHub・AI エージェント（Claude Code や Codex など）を一度も使ったことがない人を想定しています。

これらのアプリは、単純に作ってあります。好きなように転用して、AI で改変して、自分専用のアプリにしてもらって大丈夫です（MIT ライセンス）。

## このキットに入っているもの

- この手順書（`README_ja.md`）
- AI 用の手順書（スキル）: `skills/remix-app/`
  - `SKILL.md` … AI が読む作業手順。コードの入手 → 改変 → 動作確認 → 公開 を、あなたと一歩ずつ進めるように書いてあります。
  - `references/` … アプリの一覧と、GitHub の登録・公開手順。

スキルを入れておくと、AI が「どう進めるか」を知った状態で手伝ってくれます。あなたは「こうしたい」と伝えて、AI に言われたときだけボタンを押したりログインしたりすれば進みます。

## 用意するもの

1. **パソコン**（Mac / Windows / Linux）
2. **AI エージェント**（どれか1つ）
   - **Claude Code** … 初めてなら、Claude のデスクトップアプリの「Code」タブが一番手軽です。有料プランが必要です。
   - **Codex**（OpenAI）
   - その他、パソコン上のファイルを読み書きでき、コマンドを実行できる AI
3. **GitHub アカウント** … 公開したい場合だけ必要です。持っていなくても、作り方は AI が案内します。自分のパソコンで使うだけなら不要です。

Git などの道具が入っていなくても大丈夫です。足りないものは AI が確認して、入れ方を案内します。

## はじめかた

### 1. このキットをダウンロードする

このページの上の **Code** → **Download ZIP** を押し、ダウンロードした ZIP を展開します。
（Git が使える人は `git clone https://github.com/yukmmz/app-remix-kit.git` でも構いません。）

### 2. スキルを AI に入れる

展開したフォルダの中の `skills/remix-app` フォルダを、使う AI に合わせて次の場所にコピーします。

| AI | コピー先 |
|---|---|
| Claude Code | `~/.claude/skills/remix-app/`（`~` は自分のホームフォルダ） |
| Codex | `~/.codex/skills/remix-app/` |

Windows では `~` は `C:\Users\<自分のユーザー名>` のことです。Claude Code ならコピー先は `C:\Users\<自分のユーザー名>\.claude\skills\remix-app\` になります。名前が `.` で始まるフォルダは隠れていることがあるので、エクスプローラーの **表示** → **表示** → **隠しファイル** をオンにしてください（フォルダが無ければ作ります）。

フォルダの場所がわからない・コピーの仕方がわからない場合は、手順 3 で AI にこう頼めば代わりにやってくれます:

> このフォルダ（展開した場所）の skills/remix-app を、あなたが使えるスキルとして入れてください。

スキルの仕組みが無い AI では、毎回最初に次のように伝えれば同じように動きます:

> skills/remix-app/SKILL.md を読んで、その手順に従って手伝ってください。

### 3. AI に頼む

作業用のフォルダ（例: デスクトップに `my-apps` フォルダを作る）で AI を開き、やりたいことを普通の言葉で伝えます。たとえば次のように頼みます（アプリ名と内容は、あなたのやりたいことに置き換えてください）。

> （例）remix-app スキルを使って、multitask-timer を自分用に作り変えたい。タスクごとに色を自由に選べるようにしたい。

Claude Code なら `/remix-app` と入力して始めることもできます。

### 4. あとは AI と一緒に進める

AI はおおむね次の順で進めます。各段階で、あなたに確認してから次へ進みます。

1. どのアプリを、どう変えたいか、公開したいかを聞く
2. アプリのコードを手元に用意する（フォーク・ZIP ダウンロードなど）
3. まず元のまま動かして、ブラウザで開いてもらう
4. 変更内容を一緒に決める
5. 元の作者に向いた部分（フィードバックの送信先・リンク・QR コードなど）をあなたのものに差し替える
6. 少しずつ変更して、そのたびに試してもらう
7. 保存（コミット）する
8. 公開したい場合は GitHub Pages で公開する（GitHub アカウントの作成もここで案内します）

公開すると `https://<あなたのユーザー名>.github.io/<アプリ名>/` で、誰でも開けるようになります。

## 気をつけること

- **公開したものは誰でも見られます。** パスワードや個人情報をアプリに書き込まないでください。AI にも、公開の前には必ず確認するよう手順書に書いてあります。
- **元のアプリは変わりません。** あなたが変えるのは自分のコピーだけです。うまくいかなくなっても、元のアプリからやり直せます。
- **ライセンス（MIT）。** 改変・公開・配布は自由です。条件は、`LICENSE` ファイルの元の著作権表示を残すことだけです（AI がその通りに扱います）。
- AI の利用料金は、それぞれの AI サービスのプランに従います。
